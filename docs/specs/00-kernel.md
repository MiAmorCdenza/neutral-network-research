# 总纲内核规格（Kernel Spec v0.1）

- 定位：全项目共享内核——总纲 SDE（连续时间扩散骨干）、时钟系统、全局约定、元件注册与验收协议。所有分层规格依赖本文件。
- 与 v0-function-spec.md 的关系：本目录（docs/specs/）为其取代者；其中仍有效的部分（验收协议、无梯度纪律）并入本文件 K3/K5。v0 规格中的"退化路径"原则作废。

## K0 保真原则（取代"退化路径/简化优先"）

1. **数学形式保真**：每个生物学事实实现为其方程、状态变量与耦合结构的完整形式；不因"难"而裁剪机制。
2. **时间尺度工程化**：生物时间经 dt 阶梯映射（架构 §5：最快被建模时间常数 ≥10 积分步解析；慢层永不在快 dt 上积分）。
3. **剂量与时序可调**：机制默认开启；剂量（系数）与时序（时钟域）为配置项（异时性原则：改时序即改结构）。
4. **存疑事实按假说实现**：架构文档 §7 存疑条目实现为「主实现 + 可切换备选 + 测试钩子」，代码注释标注假说状态。
5. **机制留痕**：每个机制携带其生物出处（文档章节号）与验收指标；总纲规则保留：**无指标增益的机制在版本门处淘汰**（实现可以全量，留存由证据决定）。

## K1 总纲 SDE（架构 §1 直接落地）

- 前向（加噪/抽象/压缩）：`dx = f(x,t)dt + g(t)dw`
- 反向（去噪/推断/生成）：`dx = [f(x,t) − g(t)²·s_θ(x,t)]dt + g(t)dw̄`，s_θ = ∇_x log p_t(x)
- 目标（变分自由能 ≈ 去噪分数匹配 ELBO）：`min E_{t,x0,ε} λ(t)·‖s_θ(x_t,t) − ∇ log p_t(x_t|x0)‖²`，λ(t) = g(t)²

### K.F1 `sde_marginal(x0, t, sde) -> (mean, std)`
- 接口：`x0: [B,D]`，`t: [B]∈[0,1]`；返回 `mean, std: [B,D]`（p_t(x_t|x0) 的解析边缘矩）。
- 算法（VP，默认）：`β(t)=βmin+t(βmax−βmin)`；**默认 βmin=0.1、βmax=20**（即离散 DDPM 线性表 β_t∈[1e-4,0.02]、T=1000 的连续等价，Song et al. 2021 约定）；`ᾱ(t)=exp(−∫₀ᵗβ ds)=exp(−βmin·t−(βmax−βmin)·t²/2)`（线性 β 的积分有闭式，禁止数值积分）；`mean=√ᾱ·x0`；`std=√(1−ᾱ)`。
- 算法（VE）：`mean=x0`；`std=σmin·√((σmax/σmin)^{2t}−1)`。注意：σmin(σmax/σmin)^t 只是噪声**尺度参数**，不是边缘标准差（σmin→0 的极限下两者才相等）。
- 先验约束（必测）：t=1 时必须 x_1≈N(0,I)——即 `∫₀¹β ds` 足够大（默认 10.05 → ᾱ(1)≈4.3e-5，std(1)≈0.99998）。**禁止直接把离散每步常数 1e-4/0.02 当连续 β(t)**：那会得到 ᾱ(1)≈0.99、噪声几乎不加，先验不成立，扩散失效。
- 特性：[纯函数][数值安全]；t=0 时 std→0（钳制 ≥EPS=1e-6）；t 越界（<0 或 >1）抛错；输出全有限；mean/std 逐样本：t 的每行独立作用于对应样本行，同一样本各维同方差（各向同性）。

### K.F2 `sde_forward(x0, t, sde, eps=None, rng=None) -> x_t`
- 算法：`x_t = mean + std·ε`，ε~N(0,I)；eps 给定时跳过采样。
- 特性：[纯函数(eps 给定)][确定性(rng 给定)]。

### K.F3 `sde_score_target(x_t, x0, t, sde) -> s`
- 算法：`s = −(x_t − mean)/std²`。
- 特性：[纯函数]；与 K.F2 配对——同一 (x0,t,ε) 下 s = −ε/std。

### K.F4 `reverse_euler_maruyama(x, t, dt, score, sde, rng) -> x'`
- 算法：`x' = x − [f(x,t) − g(t)²·score]·dt + g(t)·√dt·z`，z~N(0,I)。
- 特性：[确定性(rng)]；dt 为负（反向时间积分）。

### K.F5 `langevin_corrector(x, t, score, snr, rng) -> x'`
- 算法：`ε² = 2(snr·σ_z/σ_s)²`；`x' = x + (ε²/2)·score + ε·z`。
- 特性：[确定性(rng)]；σ_z/σ_s 为当前 z 与 score 的经验范数比。

### K.F6 `pc_sampler(score_fn, sde, n_steps, n_correct, snr, rng) -> x0`
- 算法：predictor（K.F4 反向 Euler-Maruyama）与 corrector（K.F5 Langevin）×n_correct 交替，t: 1→0 等距。
- 特性：[确定性(rng)]；score_fn 在 eval 模式调用。

### K.F7 `dsm_loss(score_fn, x0, t, sde, eps) -> scalar`
- 算法：`L = mean(λ(t)·‖s_θ(x_t,t) − s‖²)`，λ(t)=g(t)²。
- 特性：[纯函数]；这是全项目唯一"总损失"口径（L4 价值、L5 选择压皆围绕它展开）。

## K2 时钟系统（嵌套节拍 / dt 阶梯，架构 §5 落地）

### K.F8 `Clock(dt)` / `NestedClock(clocks)`
- 语义：每时钟独立步进；嵌套比值自相似 theta:gamma:ripple ≈ 5-7:5；慢钟 1 步 = 快钟 ratio 步。
- 接口：`step() -> bool(本钟本轮是否触发)`；`phase() -> [0,2π)`；`tick`。
- 特性：[确定性]；快环精确而稀疏、慢环粗略而全局（架构原则 9）。

### K.F9 `clock_domains(cfg) -> dict[str, Clock]`
- 时钟域：`T0` 快环（每推理步，事件驱动稀疏）｜`T1` 结算（每 K 步）｜`T2` 慢场（每 N 步 EMA）｜`T3` 结构（每 K epoch）｜`T4` 周期（每轮训练/睡眠）｜`T5` 昼夜（训练周期级）。
- 特性：[确定性]；每个机制在其时钟域注册（K4），调度器按域触发。
- **名义步长契约**：`cfg.nominal_dt` 声明 1 个 T0 步对应的生物时间（V0 默认 1 ms 等效，率编码形态）；全部 τ 超参以生物时间声明、由 K2 统一换算为步数。每个机制按其时间常数分档：τ ≥ 10·nominal_dt → 完整档（dt 阶梯强制，架构 §5.1 / L9.F8 表）；τ < 10·nominal_dt → **降采样档**（必须显式标注「率近似」，不得静默违反）。

## K3 全局约定

- 记号：B=batch；D=数据维；N_l=第 l 层宽度；张量一律 batch-first、float32；`z⊗a` = `mean_b(z_b a_bᵀ)`。
- 性质标记（每个函数必须满足其标记）：
  - **[纯函数]**：无隐藏状态、不读全局 RNG、同输入必同输出、不改输入；
  - **[确定性]**：随机性只从显式 rng 流出；
  - **[无梯度]**：不产生 autograd 图、不得调用 `.backward()`；
  - **[冻结]**：张量 `requires_grad=False` 且训练中永不被修改；
  - **[数值安全]**：分母钳制、输出全有限；
  - **[递推状态]**：持有跨步持久状态（buffers），必须提供 reset()。
- **三条纪律**（违反即退回）：
  1. 生物路径零反向传播——三因素/价值/结构/维护全部走 `no_grad` + `param.data`；
  2. 基线隔离——`.backward()` 仅允许出现在 `eval.py` 的 backprop 基线中；
  3. 无隐式随机——除种子函数外，`torch.rand*` 必须带 generator。
- 命名：函数 ID 形如 `L0.F1`；实现文件 `src/bio_net/<layer>.py`；状态一律注册为 buffer。
- 包级门面与纪律执行点（__init__.py 内容规格）见 12-repo-layout §8。

## K4 元件注册表（元件库先行的机制化）

### K.F10 `register_mechanism(name, layer, clock, bio_ref, enabled, dose, lock) -> MechanismSpec`
- 语义：每个机制 = 一个元件：状态变量（buffers）+ 递推函数（T0）+ 结算函数（T1+）+ 剂量（超参表）+ 开关（enabled）+ 锁（三锁状态，L6）。
- 新结构 = 已有元件的重组与剂量/时序调整（架构原则 4）；注册表可序列化（五通道中"程序通道"的载体）。

## K5 存疑事实映射（架构 §7 → 实现标注）

| 存疑条目 | 涉及函数 | 处理 |
|---|---|---|
| 单神经元 XOR | L0.F3 树突 AND | 只用 AND/巧合检测；不实现 XOR 型树突 |
| 成人神经发生 | L6.F10 节点分裂 | 默认关闭（开关）；启用即"可选特性" |
| gamma 因果性 | L9.F1–F7 | 按待测假说实现，附消融钩子（关 gamma 通道测指标） |
| 40Hz 夹带清淀粉样 | L7.F4–F6 | 降级为候选假说，睡眠节律参数可配置 |
| 语义离散 vs 连续 | K1 SDE + 吸引子机制 | 连续潜空间，吸引子盆地由归一化竞争涌现 |

## K6 提交与验收协议（开发契约）

- 提交单位：单个函数（或自然成组 2–3 个）。提交：① 函数 ID；② 代码文件:行号；③ 单测完整输出；④ 特性自检表；⑤ **保真核对**——说明对应文档第几节哪条生物学事实，实现与方程逐行对照；存疑假说条目须附假说标签与测试钩子。
- 验收四点：接口签名一致 / 算法与方程逐行一致 / 测试覆盖全部"必要特性" / 测试通过。返回"通过"或"退回+原因"。
- 模块级闸门：模块内函数全部通过后做集成验收；V0–V8 版本门见 07-build-order.md。
