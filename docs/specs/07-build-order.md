# 构建顺序与验收映射（Build Order v0.1）

- 定位：全量规格已备（00–06），构建仍按版本门推进。原则：规格先行、机制默认开启、版本门按证据淘汰（无指标增益的机制不引入——总纲规则）。
- 开发契约：按 00-kernel §K6 提交验收；版本门全部指标通过才进入下一版。

## 版本 → 函数集映射

### V0 最小闭环（发育式骨架，保真版）
- 函数集：K.F1–K.F9（SDE 骨干 + 时钟）；DEV.F1–F8（种子展开 + 自校准）；L0.F1–F8；L1.F1–F9（三通路全量 + STP/Pr/延迟）；L5.F1–F12（完整五选择压，V0 灵魂）；L6.F2（三锁）；L4.F1–F2（最小 TD 评估器）；L2.F1–F2（低秩束 + 投影，最小形态）。
- **V0 剂量协议（防调参爆炸）**：五选择压权重（L5.F11）按序开启——第 1 档仅 RPE 结算 + 代谢（接地主线）；第 2 档加 Hebb/稳态；第 3 档加营养竞争。每档先单跑记录指标再叠加（消融即剂量阶梯）。D4-1 记录两次：默认剂量全开一次、阶梯最佳一次。
- 验收（D4 口径不变）：① 三因素收敛，与 backprop 基线差距 ≤30%；② ≥10 种子粗统计 CV≤10%、零外部数据可前向；③ 自校准增益 ≥20% 或可测提升；④ 结算延迟 K=10 性能损失 ≤10%；⑤ 活跃率 10–20% 且不损指标；⑥ 误差总线 k 扫描拐点存在。
- 交付物：`docs/v0-report.md`——六指标表 + 曲线（loss/活跃率/bus 扫描/lag）+ 对照说明。

### V1 通信细化
- 函数集：L1 全量激活验证（STP/Pr/NMDA/延迟/电突触对称）+ L1.F9 消融钩子。
- 验收：STP 降低高频伪影；Pr 提升对缺失输入鲁棒性。

### V2 介观束与锁定
- 函数集：L2.F3–F5；L6.F2/F3（关键期调度 + 三锁全量）。
- 验收：长程一致性提升；锁定后稳定性提升且可逐个解锁。

### V3 容积场
- 函数集：L3.F1–F6。
- 验收：多样性提升、空间可控性提升。

### V4 结构演化
- 函数集：L6.F4–F12（静默突触/凋亡/分裂/回收池/五通道留存）。
- 验收：参数下降不损性能；新任务适配更快。

### V5 价值层
- 函数集：L4.F3–F9 全量（难度轴/EVC/5-HT/Go-NoGo/双系统/可重指向/脱钩监控）。
- 验收：稀疏奖励任务可训练；伪影步被识别抑制；评估器可替换。

### V6 时间轴层
- 函数集：L9.F1–F8。
- 验收：多任务并行传输；预测/误差两流分离带来指标增益。

### V7 行动闭环
- 函数集：L8.F1–F4 + L8C.F1–F8 全量。
- 验收：具身/序列预测中自生成成分被正确条件化。

### V8 睡眠巩固
- 函数集：L7.F1–F8 全量。
- 验收：灾难性遗忘缓解；训练稳定性提升。

## 开发顺序（个人开发者）

1. **V0 路径**：00-kernel → 01-development（F1–F5）→ 02-L0-L1 → 04-L4-L5（L5 优先）→ 最小评估器 + 验收台。
2. 每完成一个函数提交验收（K6 协议）；模块集成闸门：L5.F12 结算回放核对（ΔW = 五选择压加权和，逐元素相等）。
3. V0 总闸门通过后，按 V1→V8 逐版展开；每版启动时如遇规格缺口，先补规格再写代码（规格先行的硬规则）。
