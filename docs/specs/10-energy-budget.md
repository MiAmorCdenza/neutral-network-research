# 能量预算系统规格（Energy Budget Spec v0.1）

- 定位：奖惩机制的**接地层实现**——全局能量账本 + 单位账户 + 能耗定价 + 存活选择。跨 L0（激活成本）/L2（布线成本）/L4（价值接地）/L5（代谢选择压）/L6（凋亡与扩张预算）/L7（SHY）的横切系统。
- 生物学依据：昂贵组织假说（Aiello & Wheeler 1995：脑 2% 质量耗 20% 能量，高能耗必须由行为收益偿还）；神经营养假说（Levi-Montalcini：神经元竞争靶区有限营养因子，发育期约 50% 凋亡）；营养竞争 NGF（连接级存活信号）；代谢选择压（表征的能耗）；五层接地链（10.5.1：热力学/代谢层是唯一物理实在——能量就是接地层）；统一数学形式（对参照的预测误差——能量稳态偏差即代谢层的预测误差）。
- 核心立场：**能量不是又一个正则项，而是奖惩与价值的币种**。五选择压全部以能量结算——RPE 是它的时间差分版，营养竞争是连接版，稳态是速率版，代谢是结构版（10.5.3 的统一落地）。

## 1. 账本模型

### 1.1 总账（全局能量池）

```
E_total(t+1) = E_total(t) + inflow(t) − cost(t)
inflow(t) = basal_rate·dt            # 基本能量供给（定期少量提供）
          + reward_influx(task)      # 完成任务 → 能量（E.F7）
cost(t)   = Σ_i [ e_maint_i + e_act·|z_i| ]        # 维持 + 激活
          + Σ_ij w_ij²·d_ij                          # 布线（距离加权）
          + Σ_struct c_struct                        # 一次性结构成本
```

- **激活成本**：`e_act·|z_i|`——L0.F5 的导数形态；稀疏编码在能量经济学下是**生存策略**而非正则（硬阈值 + 除法归一化 → 低能耗 → 存活）。
- **维持成本**：`e_maint_i`——静默单元也要付账（静息电位类比）；**规模成本天然入账**：扩张神经元数量 = 维持成本线性上升（用户的观察 1）。
- **布线成本**：`Σ w_ij²·d_ij`——L2.F4 以能量计价；长距离连接消耗更多（用户的观察 2）。
- **结构成本**：分裂 c_split、萌芽 c_sprout、静默激活 c_awaken——一次性扣款，须经预算审批（E.F6）。

### 1.2 单位账户（每单元能量余额）

- 每单元余额 `b_i`（能量流入份额 − 成本份额的 EMA）。
- **能量 credit 的分配复用资格迹**：任务完成时，奖励能量沿**同一条资格迹**分配给活动连接（E.F4）——L5.F5 rpe_settle 结算权重、E.F4 结算能量，同迹双币。学习与存活由同一机制决定（「一起放电的一起存活」Stent 1973 的账本化）。

### 1.3 执行（三级）

| 频率 | 机制 | 动作 |
|---|---|---|
| T0 每步 | E.F2/F3 收支记账 | 账本更新 |
| T1 每 K 步 | E.F4 能量结算 | 任务奖励沿资格迹分配 |
| T3 每 epoch | E.F5 存活审查 | 负余额单位 → 凋亡清单（交 L6.F7/L7.F2 执行） |
| T3 每 epoch | E.F6 扩张审批 | 分裂/萌芽/激活须能量审批（L6.F9 的能量形态） |
| 全局地板 | 饥饿状态机 | E_total < floor → 全局软凋亡（L7.F7 SHY 档）/ 暂停扩张 / 提前锁定关键期（节省可塑性代谢，假说标签） |

## 2. 与价值层的对接（接地）

- **评估器 = 对未来能量余额的预测**：`v = V(s) ≈ Σ_k γ^k·E[inflow − cost]`——「价值 = 关于持续存在的预测」（10.5）在工程上具体化为能量可持续性预测。
- **RPE 的参照 = 能量稳态**：`r_energy = 归一化(reward_influx − 预期消耗)`；`δ_v = r_energy + γ·v_next − v`（L4.F2 的接地形态）。奖惩 = 预测误差：奖励 = 能量流入超预期，惩罚 = 能量损失超预期。
- **脱钩监控可测化**（L4.F9）：ground_stream = E.F8 实际能量轨迹；valence_stream = 评估器输出；两者滑窗相关下降 = 评估器脱钩（成瘾类比：wanting 在 grounding 消失后持续升级）——现在有物理量可测。
- **评估器元选择可执行**（L4.F8/DEV.F9）：评估器按「能量轨迹预测误差」竞争——「更跟踪群体存续的评估体系」被选择，判据具体化。
- **文化层价值源必须最终兑付能量**：概念奖惩（金钱/地位）是可安装的代理（L4.F8），但代理脱钩会被 E.F8+L4.F9 检测——痛感是地基的压缩代理，概念奖惩是代理的代理，可漂移、可错，能量账本负责纠错。

### 2.5 档位条款（连续约束与事件信号的分工，架构 v0.2.2 落地）

- 连续档（处处在线的成本税）：激活成本、维持成本、布线成本——总账逐步计，塑造整个解空间。
- 事件档（稀疏的悬崖警报）：reward_influx（任务完成时）、能量 credit（E.F4 沿资格迹离散分配）、凋亡（E.F5 余额跌破阈值触发）——触发式结算，不得平滑为连续流。
- 硬规则：RPE（L4.F2）与惩罚（L4.F5）保持**事件形状**——能量账本是记账媒介，不是把悬崖抹平成斜坡。能量防「死于成本」，痛觉防「死于内容」；账本记录二者，不合并二者。
- 预期消耗：`cost_ema`（池状态，E.F1）——L4.F2 的 r_energy 以 `reward_influx − cost_ema·dt` 为预期参照。

## 3. 五选择压同币种统一

| 选择压 | 原定义（10.5.3） | 能量计价形态 |
|---|---|---|
| 营养竞争 | 连接级存活信号（靶区逆行） | 能量 credit 沿资格迹逆分配（E.F4） |
| 活动竞争 | Hebb 时间相关性 | 不变（结构由能量选择） |
| 奖惩 | RPE 预测误差 | r_energy（能量流入超预期） |
| 代谢 | 表征的能耗 | 能耗定价 → 稀疏 + 凋亡压力 |
| 稳态 | 突触缩放 | 速率目标 = 能量抽取稳定（防单单元垄断） |

## 4. 函数规格（energy.py）

### E.F1 `energy_pool(cfg) -> pool`
- 状态：`E_total: float`；`b_i: Tensor[N_units]`（单位余额 EMA）；`ledger: dict`（收支流水）。
- 接口：`reset()`；序列化（入 L6.F12 结构通道）。
- 特性：[递推状态][确定性]。

### E.F2 `energy_inflow(pool, basal_rate, task_reward, dt) -> pool'`
- 算法：`inflow = basal_rate·dt + reward_influx`；`E_total += inflow`。
- 特性：[纯函数]；basal_rate 可受昼夜节律调制（L3.F5：觉醒期供给高）——假说标签。

### E.F3 `energy_cost(z, W, positions, cfg) -> (cost_total, cost_per_unit)`
- 算法（§1.1 总账成本项）：激活 + 维持 + 布线（`w²·d`，d 来自 DEV.F2 位置）+ 一次性结构成本清单。
- 特性：[纯函数]；`cost_per_unit` 供 E.F5 余额核算。

### E.F4 `energy_settle(pool, traces, reward, cfg) -> pool'`
- 算法：`credit_ij = reward·E_ij/ΣE`（资格迹归一化分配）；`b_j += Σ_i credit_ij`（突触后单元收账）。
- 特性：[无梯度]；与 L5.F5 同一条资格迹（复用断言：结算用迹与学习用迹为同一对象）。

### E.F5 `energy_apoptosis(pool, window, theta_apop) -> prune_mask`
- 算法：`prune_i = (EMA(b_i) < θ_apop) 持续 window 步`——消耗完毕则凋亡（用户规则 1）。
- 特性：[确定性]；输出交 L6.F7 软凋亡 + L7.F2 小胶质标记执行（标记与执行分离）。

### E.F6 `energy_approve(pool, expansion_plan) -> approved_plan`
- 算法：结构变更清单 × 一次性成本（c_split/c_sprout/c_awaken）≤ 当前 E_total 余额比例上限 → 批准；**扩张必伴凋亡**（L6.F9 的能量形态：批准额度 = ρ·本期凋亡回收能量）。
- 特性：[纯函数]；未批准项回退为「静默候选」（保留在池，不执行）。

### E.F7 `reward_to_energy(task_success, cfg) -> reward_influx`
- 算法：任务完成信号 → 能量流入 `reward_influx = R·1{success}`（完成任务则提供能量，用户规则 2）。
- 特性：[纯函数]；R 为任务标定值（外部奖励与内部币种的兑换率，文化通道可配置）。

### E.F8 `ground_signal(pool) -> grounding_proxy`
- 算法：`(E_total, EMA(dE/dt), 余额分布分位数)`——接地层代理（供 L4.F1/F2 评估器输入与 L4.F9 脱钩监控的 ground_stream）。
- 特性：[纯函数]。

## 5. 集成表与验收

| 集成点 | 关系 |
|---|---|
| L0.F5 energy_cost | 成为 E.F3 的激活项（L0.F5 保留为纯算子供 E.F3 调用） |
| L2.F4 wire_cost | 以能量计价并入 E.F3（同一账本） |
| L5.F6 metabolic_regularization | 权重级快速代理；E.F3–F5 为存活级慢形态（两级并存） |
| L5.F10 retrograde_signal | 携带能量 credit（逆行信号的双币通道） |
| L6.F6 health_score | 增加能量项：`h = α1·ā + α2·|ḡ| + α3·v + α4·EMA(b_i)` |
| L6.F9 expansion_budget | 由 E.F6 审批（数量配额 + 能量配额双约束） |
| L7.F7 SHY | 饥饿状态下调档（全局地板响应） |
| L4.F1/F2、L4.F8/F9 | 评估器/RPE/元选择/脱钩监控全部以 E.F8 为接地 |

验收（V0 起逐条）：
1. **能量稳态**：无任务供给下，网络收敛到低能耗稀疏态；静默单元凋亡、活跃率回落至 D4-5 带；
2. **任务奖惩**：完成任务 → 相关单元余额上升存活；无关单元凋亡（营养竞争的存活选择）；
3. **规模成本**：分裂后总能耗上升；无收益则预算强制凋亡（稳态预算闭环）；
4. **布线成本**：长距离连接仅在贡献度足以偿债时存活（小世界拓扑涌现）；
5. **接地可测**：评估器预测与 E.F8 轨迹相关；人为注入价值漂移 → L4.F9 报警（脱钩监控冒烟）。
