# 模态课程与概念接入规格（Modality Curriculum Spec v0.1）

- 定位：回答「训练顺序」——先感知（视觉/听觉）后概念；流形与模态、概念与流形的关系；概念如何被安装而不新建结构。落地为课程阶段机 + 概念接入函数。
- 生物学依据：五层接地链（10.5.1：自下而上的接地顺序——内感受/感知 → 情感 → 联想 → 概念/文化）；神经元回收（Dehaene & Cohen 2007：阅读征用视觉词形区 VWFA、数学征用顶叶——概念不建新区，征用旧区）；语义连续、离散涌现（认知原则 2：连续基底 + 吸引子盆地）；关键期序列（视觉关键期先于语言关键期——感知先锁、概念后锁）；昂贵组织假说（概念走回收 = 免新建结构 = 能量便宜，能量预算自动选择回收）。
- 核心立场：**流形是感知基底，概念是流形之上的压缩层**。视觉与听觉是同一流形 M 的两个投影（视图）；概念不是新流形，而是 M 上的吸引子盆地 + 条件通道 + 价值源。因此顺序不是"先训练 A 能力再训练 B 能力"的切换，而是**同一条接地链自下而上的连续塑形**。

## 1. 流形与模态的关系

- 视觉、听觉天然适合流形：密集、连续、时空局部相关——它们就是 M 的投影视图（总纲：各模态状态共享一个高维连续流形）。
- 概念不适合直接上流形：稀疏、符号化、离散——它们居住在 M 的**压缩层**（吸引子盆地 = 涌现离散化；通信压缩 = 范畴边界）。
- 推论：**概念输入不建新流形**。抽象概念以三种形态接入：
  1. **条件通道**：符号/语言 → cond 向量 → 条件化感知预测（语言接地）；
  2. **吸引子涌现**：类别在感知层上涌现（神经元回收：概念读出头挂在感知层上）；
  3. **价值源**：概念奖惩经 L4.F8 安装为价值源（文化层），但必须能兑付能量（10-energy-budget 接地）。

## 2. 课程阶段机（接地链自下而上）

| 阶段 | 内容 | 接地链层 | 关键期 | 能量关系 |
|---|---|---|---|---|
| **A 感知奠基** | 视觉 + 听觉双模态，共享流形 M，跨模态对齐（C.F2） | 层 2（感知/内感受） | 先开后锁（视觉关键期类比） | 流形粗结构成型；稀疏编码被能量选择 |
| **B 概念接入** | 符号条件通道（C.F3）+ 吸引子读出（C.F4）+ 概念价值源（C.F5） | 层 3-4（情感/联想） | 后开后锁（语言关键期类比） | 概念走回收：免新建结构（昂贵组织假说的工程推论） |
| **C 抽象扩展** | 纯构造层：数学/规范/抽象价值体系 | 层 5（概念/文化） | 维持期微塑形 | 代理价值源须过脱钩监控（L4.F9） |

- **阶段 A 内部**：每模态先自发校准（Phase 1：视觉=视网膜波 DEV.F6；听觉=自发性节律活动，耳蜗波类比——假说标签），再外部数据（Phase 2）。两模态对齐 = 互条件去噪 + 对比项（C.F2）：同一事件的两个视图必须在 M 上重合。
- **阶段 B 的进入条件**：感知层粗结构达标（通道化统计 CV≤10%，D4-2 口径）+ 能量稳态（E.F5 存活审查通过）——概念安装在可承载它的地基上。
- **三锁分批安装**（L6.F2 逐模块）：感知模块先锁（PNN 锁），概念模块后锁；概念读出头的训练不重训感知层（回收而非重建）。

## 3. 函数规格（curriculum.py）

### C.F1 `modality_stage(cfg) -> stage`
- 接口：返回当前课程阶段 `{'A'|'B'|'C'}` 及进入/退出条件快照。
- 算法：阶段机：A→B 条件 = 感知粗结构 CV≤10% ∧ 能量稳态达标；B→C 条件 = 概念读出验收 ∧ 关键期三锁安装完成。
- 特性：[纯函数]；条件可配（阈值来自 D4 口径）。

### C.F2 `cross_modal_align(z_v, z_a, cfg) -> (loss, z_shared)`
- 生物：两视图共享流形——同一事件的两个投影在 M 上重合（Sperry 拓扑投射的跨模态版）。
- 算法：`z_shared = 0.5·(z_v + z_a)`（或可学习融合）；`loss = dsm_loss(互条件去噪) + λ·InfoNCE(z_v, z_a)`（互条件：以听觉为条件去噪视觉，反之亦然）。
- 特性：[纯函数]；λ 可配；两模态编码器独立、潜空间共享（接口契约）。

### C.F3 `concept_condition(symbol, vocab) -> cond_vec`
- 生物：语言接地——符号作为条件预测感知内容（文化通道经神经元回收接入感知回路）。
- 算法：`cond_vec = vocab_embed(symbol)`；注入生成器（FiLM，L3.F2 通道）。
- 特性：[纯函数]；vocab 是文化通道制品（版本化，L6.F12）；未知符号 → 专用 <unk> 向量。

### C.F4 `concept_readout(z_percept, concept_heads) -> logits`
- 生物：神经元回收——概念读出头挂在感知层激活上（VWFA 类比：符号激活了感知区）。
- 算法：`logits_c = head_c(z_percept)`；heads 训练期间感知层可塑性锁定（PNN 锁）或低剂量（异时性）。
- 特性：[纯函数]；heads 数量 = 概念数；新增概念 = 新 head + 微调（剂量调整，不新建流形）。

### C.F5 `install_value_source(name, source, energy_grounding=True) -> None`
- 生物：文化层安装新价值源（神经元回收原理：新价值源不是新机制，是旧通道的新内容）。
- 算法：注册到 L4.F8 evaluator_registry；`energy_grounding=True` 时强制绑定 E.F8 接地校验（代理价值源与能量轨迹的相关性监控）。
- 特性：[确定性]；接地校验失败 → 拒绝安装（可漂移、可错、可替换——账本纠错）。

### C.F6 `critical_period_stage(module, stage, cfg) -> lock_plan`
- 生物：关键期序列——感知先锁、概念后锁；三锁冗余且可逐个拆除（重开可塑性）。
- 算法：按模块 × 阶段返回锁安装计划（L6.F2 的调度层）；感知模块在 B 阶段开始时锁，概念模块在 B 结束时锁。
- 特性：[纯函数]；与 L6.F3 关键期开闭调度共用就绪/质量判据。

## 4. 与路线图的关系

- V0（合成 MoG，单模态占位）不变——验证学习规则 + 能量预算闭环（10-energy-budget 验收）。
- V0 之后、V5 之前：**新增阶段 A**（视觉 + 听觉双模态共享流形）——课程第一阶段；数据事件接口（09-data-events）已为此留好：事件源加 mod='visual'/'auditory' 即插即用，接口不动。
- V5 价值层：阶段 B 的自然落点（评估器可重指向 + 概念价值源安装 + 脱钩监控）。
- V7 具身：阶段 C 的完整形态（语言/动作条件 + 主动采样）。
- 课程阶段机（C.F1）是发育时间表（架构 §4）的模态细化——Phase 1/2/3/4 与阶段 A/B/C 的对应见 09-data-events §5 绑定表。

## 5. 验收

1. **跨模态对齐**：同一事件双视图在 M 上重合（配对样本潜距离 < 非配对样本；InfoNCE 区分度上升）；
2. **概念回收**：概念读出头训练前后，感知层粗结构统计变化 < 阈值（回收而非重建的度量）；
3. **接地安装**：代理价值源与能量轨迹相关性达标才可安装（C.F5 校验测试）；
4. **关键期序列**：感知锁先于概念锁；逐个解锁可重开对应模块可塑性（L6.F2 验收复用）。
