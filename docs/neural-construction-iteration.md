# 人神经系统的构建与迭代（生物学基础 v0.1）

- 定位：生物学层的基础梳理，不涉及工程实现。目标：完整刻画人神经系统「如何被构建、如何在多个时间尺度上迭代」，作为后续讨论的事实底座。
- 核心主张：人神经系统不是被设计出来的，而是四台嵌套的迭代机器（四个齿轮）在六条继承通道上连续运行的结果。理解构建 = 理解这台机器。

## 1. 总览：四个迭代齿轮与六条继承通道

### 四个齿轮（时间尺度从慢到快）

- 齿轮一：系统发生（演化，百万年级）——基因组变异 -> 发育程序重写 -> 结构出现/退化 -> 选择
- 齿轮二：个体发育（胚胎-青春期，月-年级）——过度产生 -> 活动依赖竞争 -> 稳定化
- 齿轮三：成年维持（天-年级）——活动依赖可塑性、结构周转、适应性髓鞘化、睡眠循环
- 齿轮四：文化（代际，准拉马克式）——文化工具塑造皮层重组；文化改变选择压，反哺基因演化

### 六条继承通道（信息如何跨时间传递）

1. 基因（慢，孟德尔 + 群体遗传）
2. 表观（有限，哺乳动物跨代证据弱且有争议）
3. 发育程序（基因组与环境联合「编译」）
4. 结构（成年连接模式「记住」发育史与经验史）
5. 文化（快，习得性状跨代传递）
6. 基因-文化协同（文化改写选择压）

关键：四个齿轮同时在转且互相喂料。任何单尺度模型（只讲突触可塑性，或只讲自然选择）都会失真。

## 2. 齿轮一之「结构的出现」：旧元件的新组合

### 2.1 元件库先于系统

- 突触的分子元件（突触小泡蛋白、SNARE、突触后支架同源物）在单细胞祖先（领鞭毛虫）中已存在，早于任何神经系统。
- 神经递质分子（谷氨酸、GABA、乙酰胆碱、单胺）在单细胞生物中先有代谢功能，后被「征用」为信号分子。
- 含义：结构的出现 = 已有元件的重新组合与重新定位（exaptation/co-option），而非从零发明。

### 2.2 起源与中枢化

- 海绵：无神经元，但有分泌信号细胞与部分突触蛋白。
- 刺胞动物（水螅/水母）：弥散神经网。栉水母的神经系统是否独立起源，仍存争议（Moroz 2014 与后续反驳）。
- 双侧对称动物：神经网中枢化 -> 头部化（cephalization）-> 体节化（Hox 基因控制前后轴）。
- 脊椎动物：背侧神经管；两次全基因组复制（2R 假说，Ohno 1970）-> Hox 簇翻四倍、离子通道/GPCR/细胞黏附分子家族大扩张 -> 复杂化的物质基础。

### 2.3 家族扩张产生「多样性代码」

- 原钙粘蛋白簇（哺乳动物 50+ 基因）：神经元随机组合表达 -> 每个神经元有独特「身份标签」-> 自我回避（同一神经元轴突不相连）。神经元的个体身份由分子随机性生成。
- 可变剪接：果蝇 Dscam 约 3.8 万种异构体；脊椎动物 neurexin 数千种——连接特异性在分子层生成。
- 含义：生物把「参数多样性」放在分子层生成，结构层只负责选择。

### 2.4 病毒与转座子的驯化

- 内源性逆转录病毒被驯化为功能基因：Arc（突触可塑性的核心蛋白）源自逆转录病毒 Gag，可形成类病毒颗粒在神经元间传递 RNA（Pastuzyn 2018）。
- 髓鞘出现于有颌类脊椎动物；转座子与病毒序列贡献了神经系统的多种调控元件。
- 含义：「新结构」可以来自外部遗传物质的入侵与驯化——变异源不限于点突变。

### 2.5 皮层的出现与倍增

- 哺乳动物六层新皮层由祖先的背侧 pallium 扩张而来；鸟类背侧皮层走核团路线（趋同）。
- 灵长类皮层区域倍增（视觉区、额叶区复制）；皮层柱是半自治的自组织模块。
- 脑化的代价：脑约 2% 质量消耗约 20% 能量；昂贵组织假说（Aiello & Wheeler 1995）：肠缩减为脑扩张让路。

### 2.6 人属特有的「剂量与时序调节器」

注意：人脑扩张主要不是新部件，而是旧程序的参数调整——

- ARHGAP11B（约 500 万年前的部分基因复制）：基底祖细胞增殖增强 -> 皮层折叠（小鼠/狨猴实验证实，Florio 2015）。
- NOTCH2NL（人类特有复制）：Notch 通路剂量上调 -> 皮层祖细胞扩增（Suzuki/Fiddes 2018）。
- SRGAP2C（约 240 万年前复制）：延迟树突棘成熟、增加棘密度 -> 发育减速（Charrier 2012）。
- HAR1（人类加速区，Pollard 2006）：非编码 RNA，在 Cajal-Retzius 细胞表达。
- FOXP2：与发声运动学习环路相关；但「语言基因」叙事已被修正（该变异在尼安德特人中同样存在，选择历史有争议，Atkinson 2018）。
- MYH16 假基因化（定年有争议）：咀嚼肌弱化 -> 颅骨约束释放 -> 脑扩张的可能前提（Stedman 2004）；Perry 2005 发现该假基因化在猕猴中同样存在，失活时间应早于人类-黑猩猩分歧，Stedman 的时间推断可能错误——「退化释放约束」原则成立，但此案例的因果时间线站不住。

### 2.7 结构出现的四条通路（总结）

1. 基因复制 + 新功能化/亚功能化（2R、ARHGAP11B、NOTCH2NL）
2. 转座子/逆转录病毒驯化（Arc、调控元件）
3. 调控区演化（cis-regulatory，发育重编程的主通道）
4. 发育时序重排（heterochrony/异时性，见 5.2）

## 3. 齿轮一之「变异源」：多样性从哪里来

- 基因组：点突变、结构变异、拷贝数变异；人类基因组约 5% 是片段重复（灵长类中最高），是新基因与 CNV 的富矿。
- 体细胞嵌合：LINE-1 逆转座在神经祖细胞中活跃（Muotri 2005）；海马神经元平均约 14 个独特插入（Erwin 2016，个别细胞上百）。每个神经元的基因组都不同——「网络由同一基因组展开」是错觉。
- 可变剪接与 RNA 编辑：神经元特异剪接因子（Nova/Rbfox/nSR100）；A-to-I 编辑（GluA2 的 Q/R 位点编辑缺失致死）。
- 发育作为放大器：同一基因组的发育轨迹受活动/环境扰动，展开成不同结构。变异在「展开」阶段被放大。

## 4. 齿轮一之「选择与淘汰」：多层达尔文机

### 4.1 个体间（慢）

- 自然选择：昂贵组织（脑的高能耗必须由行为收益偿还）。
- 社会脑假说（Dunbar 1998）：群体规模与皮层比例相关。
- 性选择假说（Miller）：智力/创造力作为配偶选择信号（假说）。
- 自驯化假说（Wrangham/Wilkins）：攻击性回路被社会选择削弱、幼态化（假说）。

### 4.2 个体内（细胞/突触层的达尔文机）

- 发育性凋亡：脊髓运动神经元约 50% 死亡（Hamburger 1975）；神经营养假说：神经元竞争靶区有限的神经营养因子（NGF，Levi-Montalcini）。
- 突触过度产生后修剪：皮层突触密度在幼年达到成年的约 150%，随后下降；前额叶修剪持续最久。
- 活动依赖竞争：Hebb 规则 + 神经营养竞争——「一起放电的一起存活」（Stent 1973）。
- 免疫介导消除：补体 C1q/C3 标记（Stevens 2007）、小胶质吞噬、星形胶质 MEGF10/MERTK 吞噬（Chung 2013）。
- 布线即探索-选择：生长锥随机探索 + 引导分子（netrin/slit/semaphorin/ephrin）——用「尝试-错误-淘汰」代替精确编程。

### 4.3 分子层

- 受体/突触的维持竞争：突触存活依赖持续活动验证；AMPA 受体循环是「用进废退」的分子版。

### 4.4 文化选择（齿轮四对齿轮一的反馈）

- 基因-文化协同演化：乳糖酶持久性（Tishkoff 2007）、淀粉酶拷贝数与饮食（Perry 2007）。
- 尼安德特/丹尼索瓦基因渗入：现代非非洲人约 1.5-2% 尼安德特 DNA，部分变异影响神经与免疫表型（Dannemann & Kelso 2017）。

## 5. 齿轮一之「退化」：减法即构建

### 5.1 假基因化释放约束

- MYH16 退化 -> 颅骨解放 -> 脑扩张（见 2.6）。
- 人类嗅觉受体约 60% 假基因化（小鼠约 20%）；犁鼻器受体 V1R 几乎全部假基因化，犁鼻器退化为痕迹器官。
- 原则：退化一个零件，解放一个结构。

### 5.2 幼态延续（neoteny）

- 人脑出生时仅约成年的 25%，出生后继续长大（灵长类中最长）。
- 髓鞘化推迟到 20-30 岁（前额叶）；关键期延长；SRGAP2C 延迟棘成熟。
- 含义：人类用「不成熟」买「可塑性」。大变化不必发明新零件，改时序即可。

### 5.3 发育期修剪：表面退化，实为效率化

- 青春期前额叶灰质下降 = 大规模突触修剪；与精神疾病窗口期相关（修剪异常假说）。

### 5.4 每日退化：睡眠

- SHY 突触稳态假说（Tononi & Cirelli）：睡眠全局下调突触权重，配合 SWR 回放巩固。

### 5.5 衰老与疾病：退化程序失控

- 衰老的突触丢失、髓鞘退化与发育修剪共享分子（补体）；阿尔茨海默病中补体介导的突触消除被过度激活（Hong 2016）。
- 含义：退化是受控程序；疾病是程序的失控或错误重启。

### 5.6 退化后的功能再分配

- 犁鼻器失能后，社会化学信号处理部分转移到主嗅觉系统与皮层。

## 6. 齿轮二：个体发育（过度产生 -> 选择 -> 稳定）

1. 神经诱导与区域化：BMP/Wnt/Shh/FGF 信号中心把神经板划分为区室（前脑/中脑/后脑/脊髓）。
2. 神经发生与迁移：祖细胞增殖（受 ARHGAP11B/NOTCH2NL 剂量调控）-> 放射状迁移 -> 六层由内向外建立。
3. 轴突引导：探索-选择式布线（见 4.2）。
4. 突触过度产生：达到成年约 150% 后进入修剪。
5. 关键期与稳定化：PNN 周细胞外基质、Lynx1、Nogo 受体等分子「刹车」关闭可塑性窗口（Pizzorusso 2002）；髓鞘化锁定高速通路。
6. 发育程序的可重排性：同一套工具箱（BMP/Wnt/Shh/Notch/前神经 bHLH 基因/Pax6）跨门类深度同源（deep homology）——变异主要发生在调控区与时序，而非工具箱本身。

## 6.5 发育框架理论：基因如何「不经训练」构建可用结构

核心问题（信息瓶颈）：基因组（约 3Gb、约 2 万个蛋白质编码基因）不可能直接指定约 10^14 个突触。基因只能是「压缩的生成程序」，发育是解压过程。发育框架必须同时满足三个要求：

1. 不同种子（基因型）-> 大致相同的粗结构；
2. 零外部经验时仍能快速建成可用的脑区结构，保证基本行为大致确定；
3. 保留小幅个体差异，供先天差异与后天学习分化。

生物靠五件套实现（理论框架）：

### A. 通道化（Waddington 1942/1957）

- 表观遗传景观：发育轨迹像有谷底的景观，基因与环境的扰动被谷底吸收 -> 不同基因型收敛到相似的野生型表型。
- 实现机制：冗余（多基因贡献同一性状）、剂量补偿与负反馈、阈值化（信号过阈值即触发，不敏感于精确剂量）。
- 结果：粗结构（脑区、分层、大束）高度通道化——人人相同；细结构（棘、突触权重）通道化低——人人不同。**确定性与差异性的分离发生在结构粗细两个层级，而非同一层级的折中。**

### B. 位置信息与化学亲和（Wolpert 1969；Sperry 1963）

- 形态发生素梯度（BMP/Wnt/Shh/FGF）为每个细胞提供坐标（法国国旗模型）。
- 轴突寻路用标签-受体化学亲和：ephrin/Eph 梯度生成视网膜-顶盖拓扑投射。生长锥只需响应局部化学信号，不需要全局蓝图。
- 含义：基因组不编码「连接表」，只编码「局部规则」；结构是局部规则在空间与梯度中的展开结果。

### C. 时间身份（temporal identity）

- 转录因子级联按出生顺序给祖细胞贴时间标签（果蝇神经母细胞 Hunchback -> Kruppel -> Pdm -> Castor；哺乳动物皮层六层由内向外对应 TF 序列）。
- 出生时间 + 空间位置共同决定神经元身份与连接规则 -> 层与区在无外部经验时已经确立。

### D. 自发生活动校准（最接近「零训练可用」的一环）

- 关键修正：「不经训练」的准确说法是「不经外部数据训练」。视觉通路打开之前，视网膜已产生自发波（retinal waves，Meister 1991；Katz & Shatz 1996），自产生的相关活动按 Hebb 规则预校准拓扑与眼优势柱。
- Linsker 1988：纯随机输入 + 局部 Hebb 规则即可自发涌现方向选择性结构。
- 先天行为的确定性来源 = 遗传规则建骨架 + 自发活动自监督校准 + 通道化兜底。

### E. 选择性稳定（Changeux, Courrège & Danchin 1973）

- 突触过度产生 -> 自发/早期活动选择 -> 稳定化。先天结构提供候选连接池，活动决定保留哪些。
- 这是「先天 vs 后天」的和解：结构框架先天给定，框架内的取舍由活动决定。

### 个体差异的来源（在通道化保护下产生）

1. 种子差异：基因型差异 -> 梯度阈值、受体密度、时序参数的小幅偏移；
2. 发育噪声：分裂/迁移/分枝的随机性 -> 细结构差异；
3. 体细胞嵌合（LINE-1）-> 神经元基因组互不相同；
4. 经验依赖可塑性 -> 出生后持续分化。

### 结论（回应「种子」隐喻）

生物策略：压缩程序（基因）-> 规则展开（梯度/时间身份/化学亲和）-> 通道化保证粗结构鲁棒 -> 自发活动自监督校准 -> 经验微调细结构。**种子不含树，只含生成树的程序；不同种子长出同一种树（通道化），枝叶细节各不相同（噪声 + 变异 + 经验）。**基本行为的确定性由高度通道化的粗结构 + 中央模式发生器（呼吸/吮吸/踏步等出生即工作的先天回路）保证；个体差异集中在低通道化的细结构上。

## 7. 齿轮三：成年维持

- 活动依赖可塑性：LTP/LTD/STDP、逆行信号（内源性大麻素）、短时程可塑性。
- 结构周转：成年皮层树突棘每天有约百分之几的新生与消失（小鼠数据，脑区而异）。
- 适应性髓鞘化：训练改变白质（Scholz 2009；Sagi 2012）；运动学习依赖新生少突胶质细胞（McKenzie 2014）。
- 有限神经发生：海马齿状回约每天 700 个新神经元、年周转约 1.75%（Spalding 2013，碳14测年）；成人海马神经发生是否存在仍有争议（Sorrells 2018 vs Boldrini 2018 vs Moreno-Jimenez 2019）。
- 睡眠循环：SWR 回放（巩固）+ SHY 下调（稳态）。

## 7.5 振荡与节律：大脑的时间轴（运行机制）

### 7.5.1 节律的产生：单细胞到网络

- 单细胞内在振荡：HCN（Ih）、M 电流（Kv7）、持续钠电流；锥体细胞有阈下共振（CA1 锥体细胞偏好 4-8 Hz theta 输入）。
- 网络振荡：gamma（ING/PING，PV 篮状细胞互抑制网络；间隙连接 connexin36 同步 PV 网络）；theta（内侧隔核起搏驱动海马）；慢波 <1 Hz（皮层 up-down 状态）；纺锤波 7-15 Hz（丘脑网状核起搏）；涟漪 100-250 Hz（海马局部网络事件，回放发生处）。
- 空间尺度法则（Buzsáki & Draguhn 2004）：频率越低，牵动的网络越大——涟漪局部、gamma 毫米级、theta 厘米级、慢波全脑。频率层级 = 空间层级 = 功能层级。

### 7.5.2 频段职能（含反直觉点）

| 频段 | 职能 |
|---|---|
| infra-slow（<0.1 Hz） | 唤醒基线漂移 |
| delta（0.5-4） | 深睡、稳态 |
| theta（4-8） | 导航、情景记忆、海马序列 |
| alpha（8-12） | 主动抑制性门控（注意力的遮光罩；被抑制侧 alpha 增强） |
| beta（13-30） | 维持现状（运动/基底节；帕金森 = beta 过度；动作前须 beta 去同步） |
| gamma（30-80+） | 局部计算、特征绑定、注意增益 |
| ripple（100-250） | 记忆巩固回放 |

### 7.5.3 交叉频率耦合（CFC）：多路复用

- 相位-幅度耦合（PAC）：theta-gamma 耦合——一个 theta 周期（约 125 ms）嵌套约 7 个 gamma 帧，Lisman & Idiart 1995 提出这是工作记忆 7±2 的神经基础。
- 睡眠三嵌套：慢波 up-state 嵌套纺锤波，纺锤波嵌套涟漪，涟漪携带回放（Staresina 2015）——记忆巩固的硬件结构。
- 含义：同一批神经元用不同频段同时传输多层信息——可测的物理事实，不是比喻。

### 7.5.4 相位编码：时间即地址

- 相位进动（O'Keefe & Recce 1993）：位置细胞发放相位逐周期提前，相位编码野内位置。
- theta 序列：每个 theta 周期把前方路径压缩为前瞻扫描——预测的物理形态。
- STDP 相位门控（Huerta & Lisman 1995）：theta 峰值刺激 -> LTP，波谷 -> LTD。「何时发放」决定增强还是削弱。

### 7.5.5 通过相干通信（CTC，Fries）

- 有效连接取决于相位关系：输入落在目标兴奋性窗口才被传递；节律性抑制制造通信窗口。
- 选择性路由：同一发送者用不同相位/频率对不同接收者说话——不改解剖改相位。

### 7.5.6 预测/误差的谱分离（与总纲的直接接口）

- Bastos et al. 2012：前馈（预测误差）走 gamma，反馈（预测）走 beta/alpha（Michalareas 2016 支持）。
- 与空间尺度法则同构：预测（慢、全局、自上而下）走低频大网络，误差（快、局部、自下而上）走高频小网络。

### 7.5.7 巩固与病理

- 睡眠三嵌套 = 巩固机器；Iaccarino et al. 2016：40 Hz 光刺激恢复 gamma -> AD 模型小鼠淀粉样蛋白减少（后续复现有争议）。
- 病理反证：癫痫 = 失控同步；帕金森 = 病理性 beta；精神分裂 = PV 中间神经元功能障碍 -> gamma 异常（假说）；阿尔茨海默 = gamma 瓦解。协调失败 = 功能失败。
- 争议标注：gamma 的因果角色并非定论（Ray & Maunsell 2015 发现 V1 gamma 未必随注意稳定调制）。

### 7.5.8 时间分辨率需求阶梯与嵌套时间结构

| 要保留的机制 | 特征时间 | dt 下限 |
|---|---|---|
| 全尖峰波形保真 | 1-2 ms | ~0.1 ms |
| 涟漪与巩固回放 | 4-10 ms | ~1-2 ms |
| gamma 相位编码 | 25 ms | ~2.5-5 ms |
| NMDA 巧合窗口 / STDP 时序语义 | 10-50 ms | ~5-10 ms |
| theta 序列 / 认知帧 | 125 ms | ~25 ms |

- 无全局 dt：生物是事件驱动 + 嵌套时间常数。快层（尖峰）稀疏、局部、是载波；慢变量（钙、放电率、资格迹、调质浓度）本身是低通滤波器，天然在粗时间格上运行。慢层永远不在快 dt 上积分。
- 训练与运行分离：权重更新由慢信号门控（资格迹打标，~100 ms 后或睡眠期结算）；但产生资格迹的前向动力学需要亚毫秒分辨率（若要保留 STDP 时序语义）。放弃时序语义则可放宽到 gamma 帧量级（10-25 ms）。
- 嵌套比例自相似：theta:gamma 约 5-7，gamma:ripple 约 5——信息帧比载波慢约一个数量级；载波的存在是为帧内位置（相位）与帧间时序（STDP）提供精确地址。
- 可迁移原则：最快的被建模时间常数需 >=10 个积分步解析；全层级时间常数跨约 6-7 个数量级（毫秒 -> 天）；完整系统的代价是「快环精确而稀疏 + 慢环粗略而全局」，而非「全部精确」。

## 8. 齿轮四：文化（最快的结构涌现通道）

- 神经元回收（Dehaene & Cohen 2007）：阅读、数学等文化工具征用既有皮层区（视觉词形区 VWFA 在梭状回固定位置出现）——文化在个体生命周期内「安装」新功能。
- 文化是第二套遗传系统（Richerson & Boyd 双继承理论）：习得性状跨代传递，速度快于基因。
- 基因-文化协同（见 4.4）：文化改变选择压，选择压改写基因。
- Baldwin 效应/遗传同化（Waddington 1953）：习得行为长期施加选择压后，发育程序被改写，习得变先天。

## 9. 六条继承通道（总结表）

| 通道 | 速度 | 保真度 | 方向 | 备注 |
|---|---|---|---|---|
| 基因 | 世代 | 高 | 大体单向 | 群体层面 |
| 表观 | 世代-个体 | 低/有争议 | 有限跨代 | 哺乳动物证据弱 |
| 发育程序 | 个体 | 高 | 基因组 x 环境联合编译 | 变异放大器 |
| 结构 | 个体 | 中 | 经验写入连接模式 | 「记忆」的物理形态 |
| 文化 | 代际 | 中 | 准拉马克式 | 习得性状跨代传递 |
| 基因-文化协同 | 混合 | - | 双向 | 文化改写选择压 |

## 10. 促进变异（evolvability）的核心原则

（Kirschner & Gerhart 2005；Edelman & Gally 2001）

1. 弱调控连接：模块间接口不敏感于内部参数 -> 变异可累积而不崩坏。
2. 探索性过程：生长锥探索、过度产生-修剪、免疫 V(D)J 重组——「大量随机尝试 + 选择」代替「精确编程」。在需要精确的地方，生物反而不精确编程。
3. 区室化：半自治模块（发育区、脑区、皮层柱、小脑微环路）-> 变异局部化。
4. 退化性：多结构可执行同一功能（Edelman & Gally）-> 部分损伤/变异不影响功能 -> 变异安全累积。
5. 冗余与储备：静默突触、备用通路、双侧对称。
6. 异时性：改时序即改结构——演化中最便宜的大变化通道。

## 10.5 价值理论：价值 = 关于持续存在的预测

### 10.5.1 价值不是原语：五层接地链

| 层 | 内容 | 客观性 |
|---|---|---|
| 1 热力学/代谢层 | ATP/离子梯度/氧化还原——持续存在的物理条件 | 唯一物理实在 |
| 2 内稳态/内感受层 | 体温/血糖/pH/渗透压对设定点的偏离 | 对层 1 的表征 |
| 3 情感/动机层 | 痛/愉悦/奖惩——层 2 的预测性压缩（内感受预测） | 构造 |
| 4 联想层 | 线索/情境/动作获得价值 | 构造 |
| 5 概念/文化层 | 金钱/地位/意义——经神经元回收接入层 3 | 纯构造 |

- 价值是关系量：某系统状态相对于该系统持续存在条件的偏离程度。
- 只有第一层是物理实在，以上各层都是压缩预测 -> 可以错（成瘾、进食障碍 = 价值系统偏离接地层）。
- 痛感不是地基，代谢持续才是；痛感是地基的压缩代理。

### 10.5.2 「好坏」与「难度」：同一评估器的两个正交预测轴

- 好坏 = 评估器对「结果是否有利于参照系统持续存在」的预测（效价/RPE 类信号）。
- 难度 = 评估器对「尝试成本与不确定度」的预测（努力：前扣带回/中脑边缘多巴胺，Salamone；不确定：蓝斑 NE = 意外不确定、ACh = 预期不确定，Yu & Dayan；控制的期望价值 EVC，Shenhav 2013）。
- 两者都不在世界里，在「评估器-参照系统」的关系里。解决一个问题 = 收益 - 成本 - 风险的复合预测驱动行动，结果以预测误差回写评估器与策略。

### 10.5.3 五个选择压 = 一个被代理量的五个本地代理

| 选择压 | 本地代理量 |
|---|---|
| 营养竞争（NGF） | 「你是否建立了有用连接」（靶区逆行存活信号） |
| 活动竞争（Hebb） | 时间相关性（一起放电一起存活） |
| 奖惩（DA/5-HT/NE） | 预测误差（结果比预期好/坏多少） |
| 代谢（稀疏/睡眠下调） | 表征的能耗 |
| 稳态（突触缩放） | 计算本身的稳定性 |

- 被代理量：对整体持续存在的预期贡献。没有局部信号能访问全局量 -> 必须分解 -> 这是价值本身的信用分配问题，分层代理是解。
- 统一不在同一函数，而在同一接地链 + 同一数学形式（对参照的预测误差）。RPE 是它的时间差分版，营养竞争是它的连接版，稳态是它的速率版。

### 10.5.4 概念性的后果：可漂移、可错、可替换

- 可错：wanting 不等于 liking（Berridge）——多巴胺编码激励显著性而非愉悦；成瘾 = 想要在喜欢消失后持续升级。
- 漂移是特征也是风险：概念层远距接地 -> 抽象价值体系（文明）；也 -> 病理。
- 可扩展：文化层安装新价值源（神经元回收）——新价值源不是新机制，是旧通道的新内容。
- 元选择：价值函数本身被选择；价值是持续存在的工具，工具可替换。

## 10.5.5 社会评价体系：选择放大器与评估器元选择

- 起点修正：优秀突变的默认命运是消失——新优势突变的固定概率约 2s（Haldane 1927）；人类长期有效群体规模约 1 万，漂移强劲。留存才是需要解释的例外。
- 社会体系解决的是留存阶段的放大，不是起源阶段的淘汰；且社会评估看到的是表型而非单个突变——被浓缩保留的是多基因背景。
- 三个放大机制：
  1. 性选择（配偶选择 + 同性竞争；Bateman 原理；Zahavi 诚实信号问题——信号必须昂贵到无法伪造）
  2. 地位-资源-繁殖梯度（成吉思汗 Y 染色体世系：约 0.5% 世界男性，Zerjal 2003）
  3. 同型婚配（教育同型婚配 r 约 0.4-0.5）-> 有利多基因背景浓缩 -> 加性遗传方差增大 -> Fisher 基本定理：选择速率与方差成正比
- 评估可脱钩：费舍尔失控（偏好与性状互相强化，可推向损害生存的极端）；现代人口转变（高地位群体生育率反转为负）——评估器价值函数与接地层脱钩的大规模实测。
- 五条留存通道：直接遗传 / 亲属繁殖（包容适应度，Hamilton）/ 文化繁殖 / 群体繁殖（文化群选择，Richerson & Boyd）/ 生态位继承（利基构建，Odling-Smee）。子代发展优势的大头走资源-环境-文化通道，基因通道最慢。
- 元选择：评估器本身被选择——文化群选择挑选「更跟踪群体存续」的评估体系。留存的不仅是优秀基因，更是优秀的评估体系。
- 结论：留存系统是多通道并行 + 评估器可重指向、可被元选择；社会评价体系给选择装上了放大器和方向盘。

## 11. 收束：构建与迭代的「统一算法」

人神经系统在每个尺度上都运行同一个迭代模式：

**过度产生 -> 按价值竞争/选择 -> 稳定化（锁定）-> 保留退化与再分配通道**

价值来源随尺度更换：生存（痛/奖惩，最古老）-> 代谢（能量效率）-> 活动（用进废退）-> 文化（符号/社会）。（「价值」本身的定义见 10.5）

由此回应此前讨论中「痛感奠基 -> 概念奖惩迁移」的直觉，其完整表述是：

- 痛/奖惩是内层达尔文机（细胞/突触竞争）最原始的选择压；
- 文化层（齿轮四）通过神经元回收，给内层机器安装新的选择压（概念奖惩）——「新选择压」不是新机制，而是旧选择通道上的新价值来源；
- 发展与退化是同一条受控程序的两面：退化释放约束（MYH16）、退化换取效率（青春期修剪）、退化换取稳态（睡眠 SHY），只有程序失控才成为疾病。
