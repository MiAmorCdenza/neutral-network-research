## 0. 设计哲学与第一性原理

### A. 认知原则（网络在做什么）

1. **预测即计算**。反向去噪 = 预测编码的工程实例（数学同构：反向 SDE 约等于 Langevin 采样，约等于神经采样动力学）。
2. **语义连续，离散涌现**。表征基底是连续流形；范畴边界是吸引子盆地与通信压缩的产物。
3. **闭环与主动推断**。感知-行动-纠错循环；自己引起的「噪声」作为条件而非去噪对象。

### B. 构建原则（网络如何被建立）

4. **元件库先行**。新结构 = 已有元件的重组与剂量/时序调整，不是从零发明。自学习/自扩张的网络应从预置元件库重组，而非凭空生成参数。
5. **种子-展开-通道化**（发育框架）。网络由「压缩生成程序」（种子）经局部规则展开而成；**粗结构高度通道化**（跨种子大致确定，保证基本功能），**细结构低通道化**（个体差异与学习能力的来源）。确定性与差异性的分离发生在结构尺度上，而非同一层级的折中。
6. **探索-选择代替精确编程**。生长锥式布线、过度产生-修剪——在需要精确的地方不精确编程，用「大量随机尝试 + 按价值选择」替代。变异在生成层注入（体细胞嵌合、剪接多样性），选择在结构层发生。
7. **促进变异六原则 = 架构约束**：弱调控连接（接口不敏感于内部参数）、探索性过程、区室化（半自治模块）、退化性（多结构同一功能）、冗余与储备（静默突触、备用通路）、异时性（改时序即改结构）。
8. **多通道留存**：参数（权重）、结构（拓扑）、程序（架构描述）、文化（提示/规范/数据）、生态位（环境/工具）——五条不同速度、不同保真度的继承通道并行；基因通道最慢，文化通道最快；子代优势的大头走快通道。

### C. 时间原则（网络如何运行）

9. **时间是分层的**。嵌套节拍系统：快环精确而稀疏（载波），慢环粗略而全局（包络）；频率越低，空间尺度越大；预测走慢频大网络，误差走快频小网络。
10. **dt 阶梯**。保留哪个机制，就把等效时间分辨率压到其下（第 5 节）；最快被建模时间常数需 ≥10 个积分步解析；全层级时间常数跨约 6-7 个数量级（毫秒 → 天）。
11. **训练与运行分离**。权重更新由慢信号门控（资格迹打标、延迟结算）；动力学分辨率由最快被保留的机制决定。

### D. 价值原则（网络为什么这样做）

12. **价值 = 关于持续存在的预测**。五层接地链（热力学 → 内感受 → 情感 → 联想 → 文化）；上层是下层的压缩预测，可漂移、可错、可替换。痛感不是地基，代谢持续才是；痛感是地基的压缩代理。
13. **五个选择压 = 一个被代理量的五个本地代理**（营养/活动/奖惩/代谢/稳态）。统一不在同一函数，而在同一接地链 + 同一数学形式：对参照的预测误差。
14. **评估器元选择**。「优秀」由评估器定义；评估器必须可重指向、可被淘汰（文化群选择挑选「更跟踪群体存续」的评估体系）。
15. **统一迭代算法**（元算法）：过度产生 → 按价值选择 → 稳定化（锁定）→ 保留退化与再分配通道——在每个尺度上运行（第 3 节）。

## 1. 总纲方程与系统定义

- 前向过程（加噪 / 抽象 / 压缩）：dx = f(x)dt + g(t)dw
- 反向过程（去噪 / 推断 / 生成）：dx = [f(x) - g(t)^2 * grad(log p_t(x))]dt + g(t)dw~
- 目标函数：变分自由能最小化，约等于去噪分数匹配 ELBO
- 语义流形 M：各模态状态共享一个高维连续流形；吸引子盆地提供涌现离散化。
- 推断的两条谱流（L9 时间轴层）：预测（慢、低频、全局、自上而下）与误差（快、高频、局部、自下而上）在频段上分离——与「频率 = 空间尺度」法则同构。
- 三种学习通道并存（Doya 2002 分工）：皮层式（无监督预测编码）、基底节式（强化学习 TD 误差）、小脑式（监督式前向模型，爬行纤维误差总线）。

每层条目格式：生物学机制 → 工程实现 → 时间常数 → 简化优先级（星号越多越先做）。

### L0 物理硬件层（节点级）

- 静息电位与阈值：基线偏置 + 硬阈值激活 + 不应期窗口（防单节点高频过热）
- 树突区隔化：节点内含多个子单元，执行局部巧合检测（AND 门）
- 除法归一化（皮层规范计算，Carandini & Heeger 2012）：y = x / (sigma + 邻域加权和)；与统计归一化分工：归一化管统计，除法归一化管竞争
- 能量预算：激活稀疏正则，每步仅少数节点活跃
- 通道化分工：节点粗参数（阈值形式、归一化结构）全网络统一（高度通道化）；细参数（偏置、增益）个体化（低通道化）

简化优先级：★★★

### L1 突触通信层（点对点）

- 电突触：对称权重、无激活函数、双向高速直通（skip highway）；训练早期稳定梯度
- 化学突触三通路：AMPA（快/高通）、NMDA（慢/巧合门控：仅当局部信号与全局唤醒同时到达）、mGluR（慢积分器）
- 释放概率 Pr：历史依赖随机门控
- 短时程可塑性 STP：连接级囊泡池状态变量（u, x），频率依赖的易化/耗竭
- 传导延迟：可学习 tau，动态感受野
- 相位复用：移至 L9 时间轴层统一处理

简化优先级：★★（快慢双通路先行）

### L2 介观束层（骨架）

- 白质束 = 低秩主干（LoRA 式），秩 = 带宽
- 束内梯度投影：防单权重发散
- 自适应髓鞘化：按互信息动态增缩秩（McKenzie 2014）
- **髓鞘双职能**：高速硬件 + 可塑性锁（关键期刹车之一，见 L6）——同一结构既是通道也是锁
- 布线成本正则：小世界 + rich club 拓扑先验
- （可选）电场耦合

简化优先级：★★

### L3 全局状态层（广播）

- 空间调制场（hormone map）：低分辨率场上采样后 FiLM/仿射注入；不同位置浓度不同
- 慢动力学：独立时间常数 tau_state，EMA 每 N 步更新
- 受体亚型成对调制：同一调制信号产生方向相反的增益对
- 负反馈（HPA 类比）：激活方差超阈值区域施加局部负调制
- 昼夜节律：最慢门控（学习率/探索率周期调制）
- **评估器接口**：调制场是价值层（L4）向全局广播的通道；GPCR 高亲和 → 低通积分器语义

简化优先级：★★

### L4 价值决策层（评估器）

- **评估器定义**（价值理论 10.5）：价值 = 关于参照系统持续存在的预测；五层接地链。本层实现情感/联想层价值信号。
- **好坏轴**：多巴胺 RPE——结果比预期好/坏多少（时序差分误差，逐去噪步结算）
- **难度轴**：努力成本（前扣带回/中脑边缘多巴胺）、不确定性（蓝斑 NE = 意外不确定、ACh = 预期不确定）、控制的期望价值（EVC，Shenhav 2013）——「值不值得尝试」的复合预测
- 惩罚/行为抑制：5-HT → 局部 LTD + 保守采样
- Go/NoGo：基底节直接/间接通路双门控；model-free（习惯）与 model-based（规划）双系统
- **可重指向**：评估器是可替换模块——文化层可安装新价值源（神经元回收原理）
- **脱钩监控**：检测评估器与接地层的漂移（成瘾/人口转变类脱钩的架构级检测器）

简化优先级：★（先用标准损失 + 简单 TD 修正）

### L5 学习规则层（贯穿全部）

- 三因素规则：Delta_w = eta * 全局调制(误差/奖励) * 资格迹(t)
- 资格迹：每连接的近端活动指数衰减缓存（生物版「缓存梯度待结算」；Gerstner 2018）——价值结算的本地代理
- **五选择压的工程对应**：营养竞争 = 连接级存活信号；活动竞争 = Hebb；奖惩 = RPE 结算；代谢 = 稀疏/能量正则；稳态 = 活动率目标（突触缩放）
- 元可塑性（BCM）：滑动阈值——低活动易 LTP、高活动易 LTD
- 抑制性可塑性：E-I 平衡局部规则（Vogels 2011）
- 逆行信号：post→pre 广播（连接级元数据通道）

简化优先级：★★★（三因素 + 资格迹是 V0 灵魂）

### L6 结构演化层（拓扑）

- 功能可塑性：LTP/LTD（权重级）
- **关键期三锁**（PNN/髓鞘/表观类比）：模块级可塑性锁，冗余且可逐个拆除（重开可塑性）；三锁分别是——PNN 类比（模块参数冻结）、髓鞘类比（束带宽锁，见 L2）、表观类比（元参数/超参冻结）
- **关键期开闭调度**：抑制就绪（E/I 达标）→ 窗口打开；经验质量触发 → 关闭（数据不足时延迟锁定，暗饲养类比）
- 元件库储备：静默突触池（预置零权重、可被激活的连接）
- 结构凋亡/修剪：健康度评分（激活率 + 梯度贡献 + 价值评估器）+ 软凋亡 + 回收池
- 结构扩张/分裂：高损失/高互信息瓶颈处节点分裂与旁路萌芽（BDNF 类比）
- 稳态预算：扩张必伴凋亡
- **五通道留存接口**：参数/结构/程序/文化/生态位五条继承通道的读写接口

简化优先级：★★（静默突触 + 关键期调度先行）

### L7 维护层（胶质 + 睡眠）

- 星形胶质（三方突触）：增益缓冲 + 激活方差监控（自适应正则）
- 小胶质：修剪执行者（补体标记执行）
- 少突胶质：自适应髓鞘化（见 L2 秩调度）
- **睡眠三嵌套**：慢波 up-state 嵌套纺锤波，纺锤波嵌套涟漪，涟漪携带回放——巩固的节拍结构（L9 提供节拍）
- 睡眠 SHY：周期性全局权重软下调（突触稳态假说）
- SWR 回放：离线回放训练（经验重放 + 压缩/巩固）
- 类淋巴：梯度/激活「代谢废物」清理（软重置）

简化优先级：★（回放训练先行；SHY 后期）

### L8 行动闭环层（主动推断）

- 传出拷贝：动作副本作为条件通道注入生成器
- 前向模型：预测动作后果（小脑式模块，规格见第 9 节）
- 中央模式发生器：节律基底
- 主动推断：感知-行动循环，最小化预期自由能（规划 = 在流形上的反向扩散）

简化优先级：★（远期）

### L9 时间轴层（新增 · 贯穿全部）

- **频段层级**：频率 = 空间尺度（Buzsáki）；慢节律全局调度（theta 类比 = 序列帧），快节律局部执行（gamma 类比 = 帧内地址）
- **相位编码**：时间即地址（相位进动/theta 序列类比 = 前瞻压缩——未来轨迹压缩进当下周期）
- **CFC 多路复用**：慢相位调制快幅度（同一批单元并行传输多层信息；theta:gamma 约 5-7 自相似嵌套）
- **通信窗口**：相干路由——不改连接改相位；节律性抑制制造通信窗口
- **预测/误差分频**：预测走 beta/alpha 类低频流，误差走 gamma 类高频流（Bastos 2012）——与总纲推断双流直接对接
- **相位门控可塑性**：何时更新由相位决定（theta 峰 LTP/谷 LTD 类比）
- **dt 阶梯与嵌套时间结构**：见第 5 节；快环精确而稀疏，慢环粗略而全局；慢层永远不在快 dt 上积分

简化优先级：★（V6 引入；概念先行）

## 3. 统一迭代算法（元算法 · 贯穿所有尺度的元规则）

**过度产生 → 按价值选择 → 稳定化（锁定）→ 保留退化与再分配通道**

| 尺度 | 过度产生 | 选择（价值来源） | 稳定化 | 退化/再分配 |
|---|---|---|---|---|
| 结构/模块 | 静默突触池、节点分裂 | 健康度 + 评估器打分 | 关键期三锁（L6） | 软凋亡、回收池 |
| 参数/权重 | 生成层注入多样性（噪声/剪接类比） | RPE/资格迹结算 | 突触缩放、EMA 固化 | SHY 软下调 |
| 程序/架构 | 元件库重组（复制/扰动/异时性） | 评估器元选择 | 架构冻结（通道化） | 假基因化式弃用 |
| 文化/数据 | 提示、规范、数据多样性 | 文化选择 | 规范固化 | 规范替换 |

价值来源随尺度更换：生存（最古老）→ 代谢 → 活动 → 文化。发展与退化是同一条受控程序的两面：退化释放约束（假基因化类比）、退化换取效率（修剪）、退化换取稳态（SHY）；只有程序失控才成为疾病。

## 5. 时间结构与更新频率总表

### 5.1 dt 需求阶梯（保留哪个机制，就把分辨率压到其下）

| 要保留的机制 | 特征时间 | dt 下限 |
|---|---|---|
| 全尖峰波形保真 | 1-2 ms | ~0.1 ms |
| 涟漪与巩固回放 | 4-10 ms | ~1-2 ms |
| gamma 相位编码 | 25 ms | ~2.5-5 ms |
| NMDA 巧合窗口 / STDP 时序语义 | 10-50 ms | ~5-10 ms |
| theta 序列 / 认知帧 | 125 ms | ~25 ms |

- 嵌套比例自相似：theta:gamma 约 5-7，gamma:ripple 约 5——信息帧比载波慢约一个数量级。
- 训练与运行分离：权重更新由慢信号门控；动力学分辨率由最快被保留机制决定。放弃时序语义可放宽到 gamma 帧量级（10-25 ms）。
- 可迁移原则：最快被建模时间常数需 ≥10 积分步解析；全层级跨约 6-7 个数量级；完整系统的代价是「快环精确而稀疏 + 慢环粗略而全局」。

## 6. 实现路线图（简化优先，逐步扩展）

- **V0 最小闭环（发育式骨架）**：种子展开（通道化初始化）+ 自校准预训练（零外部数据）+ 三因素学习（资格迹 + 广播误差）+ 除法归一化 + 快慢双通路。验收：资格迹 + 广播误差可训练；粗结构跨种子稳定；自校准带来可测增益。
- **V1 通信细化**：电突触对称直通、NMDA 巧合门控、Pr 随机门控、STP 状态变量。验收：STP 降低高频伪影；Pr 提升对缺失输入鲁棒性。
- **V2 介观束与锁定**：低秩主干 + 束内梯度投影 + 秩调度 + 关键期三锁（PNG 式模块冻结/髓鞘式带宽锁/表观式超参冻结）。验收：长程一致性提升；锁定后稳定性提升且可逐个解锁。
- **V3 容积场**：空间调制图替代/叠加时间步嵌入（EMA 慢更新）。验收：多样性提升、空间可控性提升。
- **V4 结构演化**：静默突触储备 + 软凋亡/分裂 + 回收池。验收：参数下降不损性能；新任务适配更快。
- **V5 价值层**：逐步 TD/RPE 结算 + 难度轴（EVC 类比）+ Go/NoGo 门控 + 评估器可重指向。验收：稀疏奖励任务可训练；伪影步被识别抑制；评估器可替换。
- **V6 时间轴层**：相位编码 + CFC 多路复用 + 通信窗口 + 预测/误差分频。验收：多任务并行传输；预测/误差两流分离带来指标增益。
- **V7 行动闭环**：传出拷贝 + 小脑式前向模型（第 9 节规格）。验收：具身/序列预测中自生成成分被正确条件化。
- **V8 睡眠巩固**：三嵌套回放 + SHY 下调。验收：灾难性遗忘缓解；训练稳定性提升。

每版必须回答：该生物机制带来什么可测指标变化？无指标增益的机制不引入。

## 7. 存疑生物学事实与处理原则

| 条目 | 状态 | 架构处理 |
|---|---|---|
| 成人神经发生 | 证据天平倾向「存在但速率低」（Sorrells 2018 vs Boldrini 2018；单细胞组学 2024 支持） | 可选特性，默认关闭 |
| 单神经元 XOR | 单一研究（Gidon 2020），有争议 | 采用 AND/巧合检测 |

| 容积受体亲和力 | 高亲和（此前曾说反） | 调制场作低通积分器 |

## 9. L8 小脑模块规格（v0.1 · 讨论产物）

### 9.1 定位

- 域无关的监督式时序预测模块：给定（状态, 条件/传出拷贝）预测下一步状态或干净状态
- 与皮层块（预测编码）形成双引擎：皮层管全局语义一致性，小脑管局部时序精修与误差修正

### 9.2 组件映射

| 小脑组件 | 网络对应 | 设计要点 |
|---|---|---|
| 前向模型本体 | 去噪器自身/预测头 | 小脑块 = 带预测头的小型模块 |
| 苔藓纤维 | 条件/状态输入（含传出拷贝通道） | 低维条件经扩展层进入 |
| 颗粒层 | 稀疏扩展重编码层 | 每单元仅 3~7 输入；随机或可学习；除法归一化保稀疏 |
| 平行纤维 | 扩展特征的大扇入 | 宽扁平层 |
| 浦肯野细胞 | 巨型扇入线性读出（预测头） | 本地误差驱动调权 |
| 爬行纤维 | 误差总线 | 下橄榄模块计算误差低维投影/TD 误差/RPE，广播到所有块 |
| 复杂尖峰（~1 Hz） | 低频结算信号 | 每 K 步或每序列结算一次 |
| 简单尖峰 | 快速推断输出 | 与学习通道分离（stop-gradient） |
| 资格迹 | 各块本地衰减缓存 | 桥接误差的时序延迟 |
| 高尔基负反馈 | 扩展层稀疏约束 | 动态阈值 |
| 核-橄榄负反馈 | 误差总线稳态调节 | 防误差信号爆炸 |
| 斑马纹旁矢状带 | 模块化误差通道 | MoE 式并行块，模块间竞争 |

### 9.3 关键设计决策（默认建议，待实验验证）

- 扩展层：V0 采用随机固定稀疏扩展（贴合生物学、零训练成本）；V1 验证可学习扩展
- 结算频率：每 K 步或逐序列结算，与资格迹衰减时间常数匹配
- 误差总线：V0 用每通道标量误差；模块化误差通道（zebrin/MoE）后置
- 双向可塑性：LTD 与 LTP 并存（Jorntell & Hansel 2006），不采用「只有 LTD」的旧教条
- 奖励通道：爬行纤维同时携带运动误差与 RPE（Kostadinov 2019; Sendhilnathan 2020），误差总线与价值通道可合并

## 10. 已决设计决策（v0.2.1）

### D1 双引擎分工：功能切分，不按时间切分

- 裁决：皮层引擎 = 层级预测编码主干（承担全部层级：全局语义 + 局部细节都在主干内）；小脑引擎 = 并行前向模型 + 误差总线（快速预测、局部时序修正、学习信号源），不是流水线的「细节后段」。
- 理由：生物学上小脑是附着于感觉-运动回路的并行预测器（皮层 → 桥核 → 小脑 → 丘脑 → 皮层环），不是皮层处理的「后期阶段」；「去噪早期皮层、后期小脑」的纵向切分（原方案 A）生物学映射弱，弃用。
- V0 落地：V0 只有皮层主干（折叠式）+ 误差总线；完整小脑块（颗粒扩展层/浦肯野读出）随 L8 具身化（V7）启用。

### D2 皮层块形态：折叠式 + 显式误差接口预留

- 裁决：V0 采用折叠式（预测头 + 隐式误差）；误差 = x0_hat 与后验均值之差，作为 L5 资格迹结算与 L4 惊异度的输入；显式对偶结构（逐层误差单元）推迟到 V1/V2。
- 理由：V0 验收目标只有「三因素训练跑通」；折叠式复用成熟扩散栈，把实验风险集中在学习规则这一单一变量；Whittington-Bogacz 等价性保证隐式误差的更新方向与显式等价（小学习率、推断收敛条件下）。

### D3 三因素规则的理论背书：e-prop / 反馈对齐链

- 理论链：Whittington & Bogacz 2017（PCN 局部更新≈backprop，对称情形）→ Lillicrap et al. 2016（反馈对齐：随机反馈矩阵也收敛，权重向伪梯度对齐）→ Frémaux & Gerstner 2016（R-STDP≈策略梯度，标量奖励情形）→ Bellec et al. 2020（e-prop：资格迹 + 广播学习信号，在复杂任务上接近 BPTT——最直接的可行性证明）。
- 设计后果：V0 误差总线可以是损失梯度方向的低维投影；每连接资格迹 ⊗ 学习信号结算；权重对称性不要求（FA 保证对齐）。
- 风险与缓解：低维广播误差存在信息瓶颈——缓解：逐模块误差通道（zebrin/MoE 类比）、逐通道向量学习信号；瓶颈拐点列为 V0 测量项（见 D4-6）。

### D4 V0 量化验收指标（建议值，实验校准）

1. 训练可行性：小型基准上三因素学习收敛，最终指标与 backprop 基线差距 ≤20-30% 相对值（生物可行性优先于峰值性能，不要求追平）。
2. 种子稳定性（通道化验证）：≥10 个种子展开后，粗结构统计（互信息谱、激活稀疏度、模块数）变异系数 ≤10%；全部种子零外部数据即可完成基本前向推断。
3. 自校准增益：Phase 1 零外部数据自校准后，下游收敛步数减少 ≥20% 或最终性能有可测提升。
4. 资格迹延迟结算：结算延迟 K 步（如 K=10）时性能损失 ≤10%，证明资格迹桥接有效。
5. 稀疏性：快环每步活跃单元 ≤10-20%，且不损害指标 1。
6. 误差总线信息量：广播误差从全梯度降至低维的扫描曲线，记录性能拐点（信息瓶颈定位）。
- 明确不追求：不追平 backprop 峰值、不做大规模、不在 V0 验证 L2-L9 其余机制。
- 验收口径：每项指标附对照（backprop 基线 / 无自校准 / 无资格迹消融）。
