# 项目构建与分割方法论（Project Decomposition v0.1）

- 版本：v0.1
- 定位：把《架构愿景》（architecture-vision.md）与《生物学基础》（neural-construction-iteration.md）翻译成个人开发者可直接执行的项目分割方案。回答三个问题：每一步实现什么、写什么函数、每个函数的接口与算法分别是什么。
- 核心立场：两份文档本身已经蕴含方法论——发育框架（种子-展开-通道化-自校准）= 项目如何从愿景展开为代码；统一迭代算法（过度产生→按价值选择→稳定化→保留退化）= 每个模块的开发工作流；关键期三锁 = 接口冻结协议；五通道留存 = 仓库分层；促进变异六原则 = 模块接口设计规范；双引擎分工（D1）= 设计文档与验收台的并行关系。
- 原则声明：愿景文档不直接指导编码，而是被编译成「模块卡片注册表」；开发者永远不面对空白页——「种子不含树，只含生成树的程序」的工程版：文档不含代码，只含生成代码的卡片。

---

## 0. 一句话方案

把项目写成一个**模块卡片注册表**：每张卡 = 一个模块的**接口契约 + 算法方程 + 验收指标 + 时钟域 + 最小完整形态**。开发 = 按序取卡 → 写最小完整形态 → 跑验收 → 锁卡。分割靠三条轴（空间/时间/版本）完成，每一步做什么由「下一张未实现的卡」决定，写什么函数由「三函数契约」决定，接口与算法直接写在卡上。

## 1. 三条分割轴

项目沿三条轴分割；任何一条轴上的位置都可以独立决定「下一步做什么」。

### 1.1 空间轴：元件库 → 组合体 → 程序（元件库先行）

- **元件（components）**：原子算子，最小或零状态。例：除法归一化 y = x/(σ + 邻域加权和)、Hebb 项、资格迹递推。
- **组合体（assemblies）**：模块 = 已有元件的重组与剂量/时序调整（原则 4），不是新代码。例：折叠式皮层块 = 成熟扩散栈 + 预测头 + 隐式误差（D2）。
- **程序（seed）**：描述「如何组装」的压缩生成程序——配置 + 局部规则（位置信息/时间身份/化学亲和类比）。
- 硬规则：新结构先问「能否由现有元件重组」；能，就不许发明新元件。

### 1.2 时间轴：时钟域（第 5.2 节更新频率表 = 调度契约）

每个模块属于且只属于一个时钟域；**更新频率是接口的一部分**：

| 时钟域 | 工程更新周期 | 属于该域的模块（例） |
|---|---|---|
| T0 推理步 | 每推理步 | 前向激活、除法归一化、快慢双通路、资格迹递推、STP 状态 |
| T1 梯度步 | 每梯度步 | 三因素结算、误差总线广播 |
| T2 慢步 | 每 N 步 EMA | 调制场、自校准门控 |
| T3 epoch 级 | 每 K epoch | 秩调度（髓鞘）、静默突触激活 |
| T4 周期级 | 每 M epoch / 每轮训练 | 关键期三锁、睡眠回放、昼夜节律 |

时钟域的工程意义：模块代码被切进对应调度器；「训练与运行分离」（原则 11）落到代码上就是——T0 的 step 绝不碰权重，权重的 update 只挂在 T1+ 时钟上。

### 1.3 版本轴：V0–V8 + 简化优先级 + 验收门

- 路线图（第 6 节）已给出 V0–V8 序列与每版验收指标；★ 数 = 开发次序权重。
- 硬规则（原文）：**每个版本必须回答：该生物机制带来什么可测指标变化？无指标增益的机制不引入。** 这就是版本轴上的选择器，防止 L4–L9 的机制在 V0 未闭环时抢先入场。

## 2. 模块卡片：「每一步实现什么」的答案

### 2.1 卡片格式（固定七节）

1. **编号与坐标**：卡片号 · 所在层 · 时钟域 · 简化优先级（★）
2. **生物学对应**：名词对照表（架构文档第 8 节）中的条目
3. **接口**：输入（名称/形状/语义）、输出、内部状态（持久变量）、超参数
4. **算法**：精确方程——不允许只有文字描述
5. **最小完整形态**（K0 取代「退化路径」）：机制不裁剪，但允许按时钟域/保真档分阶段接通（如 D3：误差总线 V0 = 损失梯度方向的低维投影——这是「低维投影」的完整形态，不是机制的简化）
6. **验收**：指标 + 阈值 + 对照/消融（D4 口径）
7. **锁定状态**：未实现 / 退化版 / 完整版 / 已锁（三锁分别打）

### 2.2 卡片示例（V0 两张）

**V0-05 · 资格迹缓存（elig_trace）**
- 层 L5 · 时钟域 T0 递推 / T1 结算 · ★★★
- 生物学对应：资格迹 = 近端活动指数衰减缓存（Gerstner 2018）
- 接口：输入 a(t)（每连接近端活动）；状态 e（形状同权重）；超参 λ（衰减率）、η（学习率）
- 算法：递推 e ← λe + a(t)；结算 Δw = η·M(t)·e
- 最小完整形态：逐连接标量缓存（不做方向性修正）——V0 档的完整实现
- 验收：D4-4——结算延迟 K=10 步时性能损失 ≤10%（对照：无资格迹即时结算）

**V0-01 · 种子展开（seed.expand）**
- 发育框架 · 时钟域 T4 构建期一次 · ★★★
- 接口：输入 种子(uint32) + 全局配置（模块数、通道化参数）；输出 粗结构（模块图 + 全网络统一的粗参数：阈值形式、归一化结构）；超参 局部规则参数
- 算法：位置信息 + 时间身份两条局部规则展开；粗参数自通道化分布采样（全网络统一），细参数留待 Phase 2 塑形
- 最小完整形态：固定手工模块图 + 通道化采样——先把「程序生成结构」这一环做对
- 验收：D4-2——≥10 种子展开，粗结构统计（互信息谱/稀疏度/模块数）CV ≤10%；零外部数据可完成基本前向推断

### 2.3 V0 卡片序列（执行顺序即开发计划）

| 序 | 卡片 | 层/机制 | 时钟域 | 验收 |
|---|---|---|---|---|
| 0 | eval 验收台骨架 | D4 六指标 + 消融 + backprop 基线 | T1 | 指标 1 对照基线可跑 |
| 1 | seed.expand 种子展开 | 发育框架 | T4 | D4-2 |
| 2 | div_norm 除法归一化 | L0 | T0 | D4-5 |
| 3 | cortical_block 折叠式皮层块 | 预测编码主干（D2） | T0 | 前向推断可用 |
| 4 | dual_path 快慢双通路 | L1 | T0 | 快通路先行 |
| 5 | elig_trace + error_bus + three_factor | L5 + 误差总线（D3） | T0/T1 | D4-1、D4-4、D4-6 |
| 6 | self_calib 自校准 | Phase 1 | T2 | D4-3 |

排序规则：依赖先行（元件→组合体→程序）；**验收台先行**（评估器定义「优秀」——先有选择标准，再过度产生）；快时钟先于慢时钟。此序列恰好覆盖 V0 定义的全部内容（种子展开 + 自校准 + 三因素学习 + 除法归一化 + 快慢双通路），且符合 D1 裁决（V0 只有皮层主干 + 误差总线）。

## 3. 三函数契约：每个模块只写这三类函数

```
init(params, rng) → state
    Phase 0 种子与展开；确定性（同 params+rng 同 state）；通道化（不同 rng 粗统计稳定）
step(state, inputs) → (outputs, state')
    T0 前向/递推；纯状态转移、零学习（原则 11：训练与运行分离）
update(state, learning_signal) → state'
    T1+ 结算；三因素 Δw = η·M·e；learning_signal 来自误差总线
慢时钟模块（T3/T4）追加两个：
schedule(state) → structural_change    # 秩调度、静默突触激活、锁安装
lock(state) / unlock(state)             # 关键期三锁开关
```

推论（可机械检查）：
- 若某函数同时做前向与学习 → 按原则 11 拆成 step/update 两个；
- 若某模块想改结构 → 只允许经 schedule/lock，不允许在 step 里改；
- 若接口需要新类型 → 先检查是否违反「弱调控连接」（第 5 节）。

## 4. 统一迭代算法 = 开发工作流（每张卡的开发循环）

| 元算法 | 生物机制 | 开发对应 |
|---|---|---|
| 过度产生 | 静默突触池、生长锥探索 | 先写**最小完整形态**（卡上第 5 节）；参数/结构搜索用随机尝试+选择 |
| 按价值选择 | 健康度 + 评估器打分 | 跑卡上第 6 节验收；达标保留，无指标增益则回退/降级 |
| 稳定化 | 关键期三锁 | 过线即锁：冻结 API、固化测试（第 6 节） |
| 保留退化/再分配 | 软凋亡、回收池、备用通路 | 旧实现以 feature flag 保留；降级模块回收为元件/卡 |

**完成定义 = 验收卡通过**，不是「功能写完了」。D4 的对照/消融口径同时给出「怎么算做完」与「为什么值得做」。

## 5. 六项促进变异原则 = 模块接口设计规范

| 原则 | 工程规则 |
|---|---|
| 弱调控连接 | 接口只传消息（张量/事件），不暴露内部参数；换实现不动接口 |
| 探索性过程 | 布线/参数/结构搜索用「随机尝试 + 选择」，不手写精确值 |
| 区室化 | 一模块一文件、半自治；重构影响局部化 |
| 退化性 | 每个接口至少两个实现（最小完整形态/全量形态），可互换、伤一不毁全 |
| 冗余与储备 | 预留接口 = 静默突触（空实现钩子）；备用通路 = feature flag 保留旧实现 |
| 异时性 | 优先改时序与剂量（配置/超参），不新增模块——「改时序即改结构」是最便宜的大变化通道（ARHGAP11B 类比） |

## 6. 关键期三锁 = 接口冻结协议

| 锁 | 生物类比 | 冻结对象 | 拆除方式 |
|---|---|---|---|
| PNN 锁 | 模块参数冻结 | 模块对外 API 与超参 | 单独解冻（重开可塑性） |
| 髓鞘锁 | 束带宽锁 | 模块间接口契约（消息格式/时序） | 版本化迁移 |
| 表观锁 | 元参数冻结 | 构建/依赖/目录结构/卡片格式 | 全库评审后整体升级 |

- **通道化分工**：粗结构（架构、接口、卡片格式）高度锁定——跨模块稳定；细结构（模块内部实现）低锁定——自由重构。确定性与差异性的分离发生在结构尺度上，不在同一层级折中。
- **重构窗口调度**（关键期开闭）：测试覆盖率达标（E/I 就绪类比）→ 窗口打开；真实使用证据（经验质量）→ 关闭。验收数据不足的模块保持「未锁」，且不允许被新模块依赖（暗饲养类比：数据不足延迟锁定）。

## 7. 五通道留存 = 仓库分层

| 通道 | 速度 | 仓库位置 | 内容 |
|---|---|---|---|
| 参数 | 最快 | 代码提交 | 实现/权重 |
| 文化 | 快 | docs/、约定 | 愿景/决策/方法论/README |
| 结构 | 中 | specs/ 卡片与架构 | 接口契约 |
| 程序 | 慢 | seed/、构建、配置 | 生成程序/构建系统 |
| 生态位 | 慢 | 依赖清单、环境 | 工具链 |

原则：**子代优势的大头走快通道**——日常进度主要发生在「参数 + 文化」两个快通道；架构重写（结构/生态位通道）是齿轮一级的罕见事件，只在版本门处发生。

## 8. 仓库结构与工作序列

> 权威目录树与函数→文件映射见 specs/12-repo-layout.md；本树为通道角色示意。

```
project/
├── docs/            # 文化通道：愿景、决策、方法论
├── specs/cards/     # 结构通道：模块卡片注册表（每卡一文件）
├── seed/            # 程序通道：种子与展开程序
├── components/      # 元件库：原子算子
├── assemblies/      # 组合体：模块 = 元件重组 + 状态
├── scheduler/       # 时钟域调度器（实现第 5.2 节表）
├── eval/            # 验收台：D4 指标 + 消融 + 基线
└── locks/           # 冻结协议：卡状态登记
```

**个人开发者的一天（固定循环）**：
1. 选卡：注册表按（依赖 → 时钟域 → ★）排序，取状态为「未实现」的下一张；
2. 读卡：接口/算法/验收已在卡上——没有空白页；
3. 写最小完整形态：只写 init/step/update（慢时钟模块加 schedule/lock）；
4. 跑验收：卡上第 6 节指标 + 对照；
5. 锁卡或回退：达标 → locks/ 登记三锁状态；不达标 → 记录数据、降级或回退——**不改卡上的验收门槛**；
6. 下一张卡。

## 9. 双引擎：设计文档是主干，验收台是误差总线

D1 的裁决直接适用于开发过程本身：**功能切分，不按时间切分**。不做「先全部设计、再全部编码」的水瀑布——设计（specs 主干）与验收（eval 台）两引擎并行运转：

- **主干引擎（慢环、全局）**：卡片注册表与架构文档——层级化预测，每版本/每周慢环回顾一次；
- **误差总线（快环、局部）**：验收台每天广播失败测试与指标差距——爬行纤维误差总线类比，它是整个项目自己的**学习信号源**；
- 预测走慢频大网络，误差走快频小网络：架构级修正只在版本门处发生（慢环），实现级修正每天发生（快环）。

于是总纲方程用在项目自己身上：**预测（卡片）= 前向模型，误差（测试失败）= 学习信号，版本门 = 结算时刻**。个人开发者就是这台机器的唯一调度器——他能明确知道每一步做什么，是因为卡片的注册表、接口、算法、验收都先于代码存在；他能承受愿景的规模，是因为任何时刻只有一张卡需要实现。
